# Neon Knockout — Championship Circuit

[Download the complete game ZIP](https://github.com/wentaopeng714-cmd/neon-knockout-circuit/releases/download/v1.0.0/neon-knockout-circuit.zip)

复古像素拳击闯关版：打赢对手 → 获得金币和个人经验 → 解锁拳手 → 到训练馆升级 → 挑战更难的 Boss。

## 使用

- `index.html` 为完整、独立、可离线打开的游戏，图像、脚本和样式全部内嵌。
- 本机试玩：`http://127.0.0.1:8766/outputs/neon-knockout-club/`
- 源码：`game.js`；UI：`index.template.html`；素材及提示词：`assets/`。
- 修改后运行 `python3 build.py`，重新生成独立 HTML。
- 无外部依赖、字体、接口或网络请求。所有产品文案使用英文。
- 可将 ZIP 或独立 HTML 交给支持上传源文件的 Loopit 编辑器；本版本未自动发布到展厅。

## 成长与训练

经验由上场拳手独立获得；金币全队共用。等级上限为 6，累计经验门槛为 0、60、160、300、480、700。

每升一级：最大血量 +8，基础伤害 +5%，能量恢复每秒 +0.8。

训练馆每个项目最多 3 级，每次费用依次为 60、120、180 金币：

- POWER：每级增加 8% 基础出拳伤害。
- HEART：每级增加 12 最大血量。
- FLOW：每级增加每秒 3 点能量恢复，并缩短闪避恢复。

失败不扣已有金币和升级；实际参与战斗并命中过的失败局可保留少量训练收益。完全没有命中的挂机失败没有奖励。

## 操作与战斗

- A / J：轻拳，可按住连续出拳。
- B / K：重拳，消耗更多能量。
- C / Space / L / 左右方向键 / 摇杆：闪避，可取消出拳。
- P / Esc：暂停。R：重赛。
- 默认静音，顶部按钮开启声音或再次静音。

闯关模式闪避有效期比原自由对战短。金色蓄力是真拳；蓝色是假动作。每套攻击中要分别闪避真实拳，最后一拳结束后才有完整 GUARD OPEN 反击窗口。仅躲过第一拳不会取消后面的连招。每次完整开口通常只适合打一次重拳。

轮次有明确倒计时，超时按失败结算。后期 Boss 的攻击顺序、快慢间隔和连击长度会变化，升级也不能替代观察与闪避。

## 五名拳手

- ROOKIE / STAR PUNCH：3 次有效轻拳充能，下一次重拳 +6 伤害。
- SKYE / DOUBLE TAP：最快轻拳，每第三次有效轻拳追加真实的 4 伤害连击。
- TANK / IRON GUARD：较高血量、较重的拳，护甲减半一次受击，每 6 秒恢复。
- RAVEN / AFTERIMAGE：较快的闪避恢复，成功闪避后下一次重拳追加 10 点紫色残影打击。
- SOL / HOT STREAK：命中积热并逐步加伤，满 5 格热量重拳额外爆发；受击失去热量。

## 美术与分享

保留原来的 360×640 画布、深紫擂台、动态观众、磨损街机控制台、像素字体和五名拳手。新增同风格的关卡地图、角色锁定、经验条、训练馆、金币奖励和角色解锁展示。高阶 Boss 有舞台灯色、精英光点和最终阶段提示。

出拳、受击、命中停顿、粒子、汗滴、残影、火焰、护甲和 KO 动画沿用并适配新战斗节奏。新增人物使用内置 image_gen 生成，参考原游戏风格；提示词见 `assets/PROMPTS.md`。

结算支持重赛、换人、训练、下一关、地图和导出 PNG 战绩卡。卡片记录实际人物、关卡、等级、金币、经验、星级、得分、闪避、连击与时长。系统支持文件分享时调用原生分享，否则可下载或保存图片。

进度存放在当前浏览器、当前站点的 localStorage 中，不是跨设备账号。浏览器拒绝存储时，训练馆会显示仅本次会话保留进度。
