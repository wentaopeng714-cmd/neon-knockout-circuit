# Character sprite generation

Tool: built-in image_gen; transparent_background=true. The original game sheet was used as a style reference. New sprites are original adult fictional fighters. Source images are embedded into the standalone index.html by build.py; game.js crops poses at runtime. No external images, fonts, scripts or API calls are required.

## skye

Use case: stylized-concept. Production transparent pixel-boxing character sheet. Match the attached reference's ORIGINAL game's art: charming chunky 16-bit arcade pixel sprites, exaggerated large expressive heads, muscular but cartoon bodies, dark plum outlines, warm three-tone cel shading, bright square highlights, clearly visible deliberately placed pixel clusters, no smooth vector art, no gradients. Reference is STYLE ONLY, create the new character described. Layout EXACTLY 2 columns by 2 rows of the SAME character, four separate full-body sprites, face RIGHT in three-quarter side view, feet baseline consistent, equal scale in all four square cells, generous transparent gutters and margins, no overlapping cells. Top-left idle boxer guard; top-right fully extended straight jab RIGHT; bottom-left powerful rising hook RIGHT with torso twist; bottom-right head snapped back LEFT, recoiling, eyes squeezed shut and sweat. Keep face, clothes and body identical across all poses. All gloves, hair and boots fully within each cell. Genuine transparent background, NO background, no labels, no UI, no lettering. Each sprite approximately 96x128 logical pixel detail, same quality as reference. SKYE is an ORIGINAL adult female speed boxer, lean athletic build, dark brown skin, two long black braids tied with a coral-orange headband, expressive confident face, TURQUOISE boxing gloves, dark teal sports crop top, white waistband, navy boxing shorts with turquoise side stripes, turquoise/white high boxing boots. Distinct lively silhouette, quick light stance.
